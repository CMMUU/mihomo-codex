# mihomo-codex v0.3.1

首个 GitHub 私有仓库版本，将原 Mihomo Desktop 统一更名为 `mihomo-codex`。

## 下载

- `mihomo-codex_0.3.1_aarch64.dmg`：macOS Apple Silicon 安装包，最低 macOS 13。
- `mihomo-v1.19.30-source.tar.gz`：随包 Mihomo 核心的官方固定版本源码归档。
- `Mihomo-LICENSE-v1.19.30.txt`：核心的原始 GPL v3 许可证。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。
- GitHub 自动提供的 Source code 压缩包对应 `v0.3.1` 标签中的源码。

在安装包所在目录核对文件：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## 功能与变更

- 统一项目、应用、窗口、菜单、托盘和主程序名称为 `mihomo-codex`。
- Rust + Tauri 2 桌面客户端，固定使用 Mihomo 1.19.30 核心。
- 订阅导入与刷新、版本化配置、激活与回滚。
- 系统代理、Manual、TUN 模式，以及代理组、节点、规则、连接、日志和诊断界面。
- OpenAI 专用候选节点检测、最多 10 个节点的自动灾备策略与带宽排序。
- 独立于代理核心的全局流量显示和 macOS 菜单栏组件。
- macOS app 包含 TUN Helper，可在应用设置中单独安装授权；安装包本身不会自动启用该服务。
- 保留原 bundle identifier 与用户数据路径，从原 Mihomo Desktop 升级继续使用现有订阅和设置。
- 更正历史 Mihomo 许可证误标，按固定上游版本保留 GPL v3 文本、附带核心源码，并增加许可证哈希校验。首版安装包已在更正后重新打包与签名。

## 已验证

- 名称/版本/兼容身份与固定上游许可证一致性检查通过。
- TypeScript / Vite 构建、Rust fmt、Clippy 通过。
- Rust 测试 37 项通过，1 项依赖真实外部订阅的测试按环境要求忽略。
- Mihomo 最小配置原生校验通过。

- 本机从 0.1.0 升级至 0.3.1，实际打开设置页确认版本，现有 3 个配置档案与设置保留。

## 验证范围

- 附件为本地构建并采用 ad-hoc 签名的 macOS ARM64 版本，没有 Developer ID 公证。
