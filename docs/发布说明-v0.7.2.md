# RouteDeck v0.7.2

## 苹果风格界面

- 按确认的效果图统一侧栏、彩色线性图标、字体层级、设置分组和轻量卡片。
- 统一导航选中、悬停、键盘聚焦及滚动条圆角，避免交互时出现直角背景。
- 同步适配浅色、深色、深紫和窄窗口。保留 Windows 原生标题栏、手动模式及全部已有功能。

## 国内更新源优先

- 设置中的“自动（国内优先）”在最高稳定版本相同时优先选择 Gitee，GitHub 作为备用下载源。
- Gitee 暂不可用或尚未同步新版时，仍可从 GitHub 获取最高稳定版，不会降级本地应用。
- 下载回退仅限版本、大小、SHA-256 和 Minisign 签名全部一致的安装包。两站独立选择和更新偏好保存继续保留。
- 检查和下载不会停止代理。安装前仍需用户确认，并明确提示安装和重启会短暂中断连接。

## 升级说明

已安装 0.7.1 正式版的用户可在“设置 → 软件更新”检查并下载安装本版。0.6.x 只有发布页检查入口，需首次手动运行官方正式安装包；之后支持软件内下载安装。

应用身份与数据目录保持不变。建议安装前备份数据并结束重要连接，安装完成后核对版本。Windows 使用对应的 NSIS/MSI 更新包；macOS 使用签名归档；Linux 内置更新仅支持 AppImage，deb/rpm 沿用包管理器。

发布前验证包含前端回归、生产构建、Rust 检查及发布脚本测试；正式附件由六平台签名工作流生成并校验。未在用户正在运行的应用上进行安装或代理切换测试。更新签名不等于 Windows Authenticode 签名或 Apple 公证。

各渠道以实际清单和附件校验结果为准，本文本身不代表 Gitee 镜像已经同步完成。
