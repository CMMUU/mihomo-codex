# mihomo-codex v0.3.2

新增独立的浅色、深色、深紫与跟随系统外观，修复此前浅色/深色被历史样式覆盖的问题。

## 外观主题

| 主题 | 风格 |
|---|---|
| 浅色 | 白色、浅灰背景，深色文字 |
| 深色 | 中性炭灰背景，不带紫色风格 |
| 深紫 | 独立的深紫玻璃与紫色光晕 |
| 跟随系统 | 随系统在浅色、深色之间切换，不自动选择深紫 |

- 设置中的主题卡片点击立即生效并自动保存。
- 应用重载后保留选择，支持键盘方向键和 Home/End 切换。
- 保存失败时恢复此前外观，防止连续点击产生并发写入。
- 通过刷新版本校验，阻止较早发起的刷新覆盖刚保存的主题。
- 新增只修改主题的设置命令，不改动代理端口、订阅、自动启动配置或控制凭据。
- 切换主题保留运行设置表单中尚未提交的输入。
- 主题会映射到原生窗口外观；深色与深紫映射原生 Dark，浅色映射 Light，跟随系统取消强制外观。
- 修正 Windows 严格 Clippy 检查中的平台条件编译警告，不改变既有权限处理和代理行为。
