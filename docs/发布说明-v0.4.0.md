# mihomo-codex v0.4.0

全新「双路汇聚」图标，以及可视化规则管理、高级文本入口、持久化与历史回滚。

## 新功能

- 「规则」分为我的规则、高级文本、生效规则三个入口。
- 可视化增删改、启停、上下排序和备注，支持域名、IP、进程、网络与端口等常用条件。
- 高级文本支持逐行规则、YAML 列表、仅含 `rules:` 的 YAML；复杂规则保留原始表达式。
- 导入规则文件；导出为可复制的只读文本，支持复制失败时全选并手动复制，不把准备文本误报为已写入文件。
- 自定义规则独立保存，订阅刷新后保留；启用规则排在托管 AI 和订阅规则之前。
- 保存前检查规则结构、策略名称和 Mihomo 原生语法；草稿变更后重新校验。
- 保留最近 20 个旧版本，回滚经过校验并产生新的递增版本。
- 并发保存、配置切换、旧请求返回均有保护；保存失败保留草稿，并尝试恢复此前运行配置。
- 图标与侧栏统一更新，原浅色、深色、深紫和系统外观继续保留。

## 使用

「规则 → 我的规则」添加规则 → 调整顺序 →「校验草稿」→「保存并应用」。高级配置和历史回滚在同页完成。

`DIRECT` 是 Mihomo 内部的直连出口，不是系统代理例外或 PAC 配置。使用 `Rule` 模式执行规则匹配。进程匹配取决于连接进入内核后可获得的进程信息。

导出含本应用的规则元数据注释，用于保留启停和备注；不是完整订阅配置。其他客户端导入前需自行处理停用条目。
