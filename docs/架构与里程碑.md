## 当前版本

- 应用：0.4.0
- Mihomo：1.19.30
- 平台：macOS、Linux、Windows
- 核心架构：Tauri WebView → Rust 应用服务 → Mihomo sidecar → 平台网络适配

## 已完成

1. 六个 target triple 的 Mihomo 资产清单、SHA-256、下载、解压和 Tauri sidecar 打包。
2. HTTPS 订阅、本地 YAML、4 MiB 限制、条件请求和安全重定向策略。
3. UUID 配置档案、不可变 revision、原始／effective 配置、激活和回滚。
4. mixed port、controller、secret、allow-lan、TUN 等本机字段安全覆盖。
5. Mihomo 原生校验、端口预检、运行状态、日志、单实例、托盘和退出清理。
6. Mihomo API：代理组、节点切换、延迟、规则、连接和关闭连接。
7. Manual、System Proxy、TUN 三种配置模式。
8. macOS networksetup、Windows WinINET、Linux GNOME gsettings 代理适配。
9. 概览、配置、代理、规则、连接、日志、诊断和设置页面。
10. 毛玻璃主页网络控制中心、System Proxy／TUN 开关和订阅 Global／Rule／Direct 分段控制。
11. CSP、最小 capability、WebView secret 隔离和日志脱敏。
12. macOS DMG 构建、三平台 CI／Release workflow。
13. Figma-first 订阅管理页、远程订阅摘要、刷新／激活／版本／删除和安全检查入口。
14. 当前节点详情：递归代理链、Provider、脱敏服务器、协议、延迟历史与重新测速。
15. System Proxy 三阶段事务保护：接管前预检、系统设置读回、接管后复检，失败自动恢复。
16. macOS 默认路由接口优先选择，只修改活动物理网络服务并排除空 Device 虚拟服务。
17. 自动组统一 HTTPS 204 健康检查，并从 effective 配置过滤订阅状态伪节点。
18. OS 全局实时流量监控：Mihomo 停止时仍采样物理接口，应用内和 macOS 菜单栏均采用上行在上、下行在下的紧凑组件。
19. 设置 schema v3：`showGlobalTraffic` 默认开启，可独立关闭采样、应用内组件和动态状态栏图标。
20. 四种独立外观：浅色、深色、深紫、跟随系统；主题专用持久化与原生窗口外观同步。
21. 全局可视化规则与高级文本入口：排序、启停、备注、校验、持久化、20 个历史快照和回滚。
22. 配置变更共享事务锁，基于原订阅重建有效配置，热更新失败恢复旧配置；规则文件采用独立版本号阻止并发覆盖。
