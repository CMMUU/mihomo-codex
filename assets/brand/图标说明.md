# mihomo-codex 应用图标

设计名称：双路汇聚。

深靛紫色圆角方形底板，白色至浅紫色的双路由 M 形标记，青色与紫色端点。应用图标与侧栏品牌图使用同一份设计。

- 生成方式：Codex 内置 ImageGen。
- 设计源图：`mihomo-codex-icon.png`，1254 × 1254 RGBA PNG，保留透明外缘。
- 侧栏图：`app-icon-128.png`。
- 各平台安装图标：由 Tauri CLI 生成，保存在 `src-tauri/icons/`。
- 应用名称、bundle identifier、用户数据目录不因图标变化而改变。

## 生成提示词

Create one production-ready macOS icon for mihomo-codex, a network routing and AI connectivity utility. Transparent canvas around a centered midnight-indigo/violet squircle. A bold original M-shaped routing mark made from two joined near-white/lavender paths, cyan and violet terminal accents, generous negative space, readable at 16–32 px. Front-on native Apple-style craftsmanship with modest depth. No words, badges, existing company logos, or multiple variants.

## 格式生成

```bash
npm run tauri -- icon assets/brand/mihomo-codex-icon.png -o src-tauri/icons
```

项目当前发布桌面版本，只维护本项目使用的桌面 PNG、ICO、ICNS；移动端产物不代表应用已支持移动平台。
